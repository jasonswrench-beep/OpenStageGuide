OPENSTAGE / GUIDE

Build a guide and share the right copy

OpenStage Guide is the OpenStage family’s Word authoring prototype. Keep the master for teaching and editing; prepare separate learner files for class. Some current features have automated checks only. Review exported files before classroom use.

Author and save · Learner copies · Know your files · Backups · Slide reviews

Author and save

When a connected prototype session is available, start in Course. Enter a title and optional audience, purpose, authors and attribution, then submit the form. All four private details are saved with the initial course at revision zero in one operation; they stay out of current public exports. Course setup guidance and example is optional read-only help. Opening/closing it never fills or changes your entries. Validation, stale-document or uncertain-save errors keep your entries; preserve them before closing the panel. An existing course cannot be replaced through setup. Choose Minimal for the existing title-and-learning-module start. Wrench is a partial private front-matter starter for a new blank supported DOCX only: Opening is mandatory; Getting started, Background, Development team / acknowledgements and Program overview are optional. Write their content directly in Word. They are private authoring sections, excluded from current public outputs and learning-module destinations/timing. Wrench checks the full captured document before preparation and before insertion, and checks the body again before writing. Nonblank or unsupported documents are refused without clearing them. Missing or partially inserted fields pause recovery; it never repeats insertion. After confirmed creation, manual text/formatting and extra content stay authoritative; refresh before subsequent panel edits. Newer Wrench masters require a matching add-in version. This supplies semantic headings and real empty body fields, not the original template’s exact layout. Cover/contents, institutional/delivery targets, complete template fidelity and full student/experienced modes remain unfinished.

Continue with Module and Activity. Select the activity’s destination module before inserting. Earlier modules are supported: the activity follows that module’s existing work and precedes the next module. Incomplete or manually rearranged managed content can pause insertion.

Edit titles, objectives, participant instructions, facilitator instructions and answers directly in their Word fields. Use Refresh from Word afterward. Keep managed controls in place; copying or removing them can require recovery.

In the course outline, the content filter “No recorded materials” shows activities with no supported saved material entries. It is an authoring reminder: an activity may still require supplies, and even a recorded list may be incomplete. Search text and instructional-cue filters can narrow these results. Module headings provide context; the filter does not edit saved requirements or search private material notes. Refresh from Word for newer saved activity data.

For minutes and writing lines, choose Edit existing activity settings, select an activity, Load current settings, then Save activity settings. Reload after other edits; stale forms are refused. Changing an existing icon and moving activities remain unavailable.

Course details use Load current course details and Save course details. Audience, purpose, authors and attribution stay in the private master, outside current learner exports. In Materials, Load current materials before editing and Save activity materials afterward. Adding a draft row alone does not save it.

After panel changes are saved to the course, also save the Word document. Saving Word does not preserve session-only library entries, slide reviews or unfinished panel drafts. Download available private records before closing the session. Unsaved course/activity forms and name/tag edits have no general draft download; complete or separately preserve that work before closing.

Reuse work and preserve drafts

In Activity Library, name/tag the Activity form and Save current activity form as a new copy. Use this copy in the activity form loads an independent draft: review it, choose a module and insert it. Original edits do not update inserted copies. Download library preserves the session catalog; Check and add file entries imports a saved catalog. Name/tag changes and removal affect only session copies. Use removal undo while available; only the latest removal is retained, and conflicts cannot overwrite newer catalog work.

To revise a saved copy, Load selected content for editing opens a separate stored-content form without changing your Activity insertion draft. Edit title, cue, minutes, learner/teacher text and writing lines, confirm review, then Save reviewed library content. Edit or remove stored material rows, or enter a new row and choose Add or apply material entry. Use Clear unfinished material entry to cancel an unfinished row edit. Invalid entries stay in the editor; add/apply or clear them before reviewing and saving. Emptying the list records an explicit empty list. These changes affect this library copy only. Save to the session catalog, then Download library to keep it. Unsaved stored-editor text is not included in that download. Preserve and Discard stored-content draft before loading another copy or using Undo last stored-content edit. Only the last real content change has an undo; changed or removed entries cannot be silently overwritten or recreated. Content editing needs no destination module and remains available while course operations are paused. Existing loaded/inserted copies stay independent.

Download private materials draft keeps supplies and unfinished entry text separately. Before Restore draft for selected activity, preserve/discard any active draft and select the matching course/activity. Compare restored requirements with saved requirements and confirm review before saving. Restore itself does not save them to Word. Supply totals assume sequential activities with reusable items available again; units are not converted and completeness is not certified.

Export a materials checklist

In Materials, save activity requirements first. Choose Refresh checklist preview, choose Full course or a saved plan in Checklist scope, then review the exact supplies, selected activity labels, project ID/revision and generation stamp, then confirm the review checkbox and choose Download new materials checklist. It uses the checked saved course record; also save Word to keep changes on disk. Unfinished material entries and private preparation notes are excluded. A changed or paused course requires a fresh preview and review.

Consumed or retained quantities add; reusable supplies use the largest activity requirement for sequential sharing. Quantities are recorded activity totals, with unit case preserved and no conversion, per-person inference, parallel allowance or stock deduction. The checklist reports recorded/total activity coverage and explicitly does not certify completeness. An empty output says “No materials recorded”; activities may still need supplies. It creates a generic, uniquely named new DOCX, with no existing-file replacement or regeneration. Unsupported XML characters in selected public text are refused before export while drafts and the master are kept. All public previews/files share valid multilingual/emoji handling, consistent line endings and existing safe omission of nonprinting control marks; private excluded fields are not rewritten.

Prepare learner copies

  1. Use Review Guide and Refresh review. Resolve required errors and review unfinished prompts, objectives and timing. This does not assess teaching quality or replace an accessibility review.
  2. In Workbook, choose Full course or a saved plan in Workbook scope, then Refresh and preview. A selected workbook includes only selected activities in saved plan order, inherited objectives from their selected modules, learner instructions and writing space. Selection does not confirm objective coverage. Review its exact scope and limits and check the selected-plan review box before Download new participant workbook.
  3. For a new design, use New workbook design preview in Workbook. Choose one of five designs, optionally enter organization-brand overrides, then Refresh new-copy design preview. Blank overrides use each design’s own defaults. The review shows the actual applied text colors, type, writing space and complete saved learner content. Unsafe requests keep their typed values; any suggested change requires the separate Use suggested values action and a fresh review. Check the exact design review box before Apply to NEW workbook copy. This creates a uniquely named generated DOCX and leaves the Word master and existing copies untouched. The source preview is not a rendered Word page; inspect its layout and accessibility before sharing. One optional informative PNG logo is available on an explicitly included public cover. Select it locally, author its description and width, and review its normalized pixel preview and actual fitted size. Selection and logo fields remain session-only unless explicitly saved in a design bundle; no automatic storage in presets or the saved course is added. Failed replacement requires an explicit Restore before using a previous image. Decorative/JPEG/SVG/background images, headers, footers, arbitrary manual Word additions and in-place transfer remain unavailable. Original image pixels are not recolored by grayscale print mode; review appearance, alt quality and accessibility before sharing.
  4. In Timing & Agenda, set the start time, Refresh agenda, review the schedule, then Download new agenda. It contains planned module/activity titles and timing, without participant instructions.
  5. For a separate named delivery plan, choose Start a new plan draft, add existing activities in the desired module-group order, enter an optional target, check the exact review box, and Save reviewed plan. Load selected plan for editing restores a saved plan; Discard plan draft clears only unsaved editor work. Select the plan in Agenda, refresh, review its exact scope and schedule, then download a new plan agenda. A plan with no selected activities has no downloadable agenda. Plans never rearrange the Word master. Agenda, Workbook and Materials each have an independent plan choice; the private facilitator copy remains full course.
  6. After edits, refresh and review again. A failed freshness check withholds the offered download. Each command offers a uniquely named new file and does not open or replace an existing output. Audience and prerequisite policy and existing-output regeneration remain unavailable. Selected-plan ZIP delivery packs are available after their own complete review.

Inspect saved files for content, layout and accessibility before sharing. Output edits do not update the master. Private information entered into a learner-facing title, objective or participant field will appear in the relevant output.

Author-declared objective design coverage

Activity settings offers Load activity objective links for the selected existing activity. Link it to any current module’s single nonblank objective, with explicit practice/assessment roles and a private rationale. Cross-module and many-to-many links are supported; cue labels, titles and location never infer links. Review the loaded objective text, apply/clear raw entries, review the complete draft, then Save activity objective links. New links and reapproved text require explicit current-objective review. Existing old snapshots remain unchanged unless you expressly re-review them. Preserve work before Discard objective-link draft; stale/uncertain saves keep raw notes, rows and Activity insertion work.

Review Guide separately displays full-course design mapping and private per-role gap notes. Load private gap note before Save private gap note. New or reapproved notes require exact current-objective review; editing an old note without that approval retains its old reviewed text. Blank/changed objectives keep old links/notes visible as stale and uncounted. Gap notes acknowledge gaps and never supply coverage; links plus a gap note show a conflict suggestion rather than deleting either. Missing/stale/unsupported mapping does not add errors that block existing exports. Unsupported versions/foreign/duplicate data stay preserved and visibly unsupported, with annotation edits refused. Keep or separately preserve raw work before Discard gap-note draft.

Coverage is author-declared design intent, not proof of learning or measurement validity. It stays in the same-project master/full backup. Current public outputs, private facilitator copy and portable activity/library copies exclude annotation IDs, reviewed snapshots and private notes; new activity copies start unlinked. Multiple objectives per module, a separate objective registry, prerequisites, variants, rubrics, validity and native accessibility remain future work.

Editable assessment starters and safe Activity loads

In Activity, choose one of three original editable starters, then Load assessment starter into Activity. Level 1 invites experience/usefulness feedback and does not prove learning. Level 2 asks you to author an objective, task and success criterion, with private administration and an authored key. Level 3 asks for application, barriers, an action plan and an author-defined follow-up interval; self-report does not prove causal impact. No validated instrument, automatic scoring, response collection or scheduled follow-up is supplied.

Replace every recognized [insert …] prompt and justify suitability in the private facilitator field. The unresolved list and explicit starter review cover the exact raw draft and destination; edits require review again. Keys stay in the private answer field. The three public outputs exclude suitability, administration and keys; the private facilitator copy includes keys only when its answer choice is enabled. Built-in origin stays in this session and does not create a library entry or claim library provenance.

Library and starter loads share the same safeguard. If a load would replace active work, it keeps your raw values, unfinished numbers/materials, origin and review. Choose Keep current Activity draft or, after preserving it as needed, Discard current draft and load selected copy. A changed draft or source requires a new replacement request. Destination selection is retained. Keeping a draft retains the panel session, not a saved file; preserve work before closing. Successful insertion clears only the exact submitted draft; newer form work survives success, interruption and recovery. A library save is still an explicit independent copy, and later source edits do not propagate into inserted activities.

Private facilitator copy

The Workbook tab also offers Private facilitator guide — structured copy. Full course is the default and contains saved teaching directions, supported course details and authored attribution, nonempty known front matter, module objectives, cue labels/durations and activity supplies/preparation notes. Choose a saved plan in Private facilitator copy scope for a separate selected copy: only selected nonempty module groups and activities appear in saved plan order, with inherited selected-module objectives. Course details and front matter are omitted from that selected copy. Include answers/debrief and Include participant instructions are separate choices, both off initially. Writing-line information appears only with selected participant content; no response-space pages are generated. Empty optional sections are omitted and unfinished authoring suggestions are shown.

Refresh private facilitator preview shows the exact complete private text, choices, project ID/revision and generation stamp. Review it and confirm the private-copy checkbox before Download new private facilitator copy. Course/private-text/choice/review changes or interrupted packaging withhold download and require another review; unfinished drafts stay intact. The generic UUID filename creates a separate new DOCX. Full and selected scopes each require their own exact private review; answers/debrief and participant instructions remain separate choices, both off by default. This copy omits unmanaged Word additions, images, formatting/layout, headers/footers, attachments and full-master fidelity. Keep your original and full backup. Edits do not flow back; audience/prerequisite/required-objective policies, exact template layout and output regeneration remain open. Selected-plan ZIP delivery packs have a separate review. Share only with intended facilitators.

Back up and restore into a separate copy

In Backups, finish the current operation and Prepare full backup. Keep the downloaded package. Select that saved file and Verify saved backup before Download restored Word copy. Integrity checks do not certify the author. Open/save the newly named restored master separately when testing is available; the current guide stays in place. Backups do not replace saving Word or private session drafts. Current limits: 64 MB master, 80 MB backup.

If operations pause, preserve the file and available drafts. Check and recover checks managed content and may save reconciled records; it does not replay insertion or undo partial writes. Missing, duplicated or unexpected fields may require a previously saved copy. Keep recovery files private.

Review slides without applying them to Word

In PowerPoint Review, select a standard local PPTX and Read slides into a review draft. Inspect extracted titles, text, speaker notes and warnings. This is not visual slide rendering; images, inherited layout text and media may be missing. Original extraction stays separate from your edits.

Save slide review in this session before switching slides. Download private review draft preserves saved review plus the current unsaved editor. To restore, choose the private record and exact original PPTX, then Restore review using the selected matching PPTX. Old module proposals still need review for the current course.

Select a revised PPTX, confirm comparison intent and Compare extracted slide content. Original, local saved/unsaved review and incoming text remain separate; matches are proposals, not proof of shared history. Editing clears stale results. Keep both decks and the review record to repeat comparison. Applying reviewed slides/updates to Word, rendering and baseline promotion remain unavailable.

Support and rights

In Prototype notes and recovery, Check loaded build compares observed code to the server snapshot; it does not prove newest source or Word compatibility. Download diagnostic record is code-only support information. Installation, connection repair and testing arrangements are separate from authoring; this guide does not authorize restart or trust changes.

Session assessment drafts and synthetic score tests

Open Assessments to draft original Likert-type or semantic-differential items and explicit subscale rules. Agreement, frequency, importance and position starting points are editable; their labels and numeric codes are separate from stable option IDs. Save item and rule drafts, review the full definition, then capture its exact version for a single synthetic-response test. Changing captured content requires a new authored version number. Replacing the tester asks before clearing existing responses.

Assessment work stays in this pane session unless you explicitly save or load a PRIVATE authoring JSON file. Use Save PRIVATE authoring draft to retain definition/item/subscale data including unfinished raw text, or Save PRIVATE definition (checked format) for a structurally checked definition with no unfinished editor work. File/structure checks do not establish psychometric validation, norms or cutoffs. These files contain scoring codes, reverse keys and rules, so keep them PRIVATE rather than distributing them as respondent assessments. They exclude synthetic responses, scores, review consent and separate Word-export instructions, copy choice and language. Load checks the file before a Keep/Replace choice, preserves current work on error or cancellation and restores authoring data as an uncaptured editable draft. Current Word-export choices remain and need fresh review. A same ID/version conflict with previously recorded content in this pane requires a new authored version before checked-definition Save, review or capture. A validated-definition download attempt and a confirmed definition-file Load record the exact ID/version in this pane. That identity ledger is not durable or a global published registry. No automatic storage, response saving, transmission, course migration or Word insertion is supplied. Switching sections within the same pane preserves current work; another Word document can start another pane, and closing/reloading can lose unsaved session data. A best-effort unload warning may not be shown by Word. Use synthetic responses.

Raw choices stay separate from reverse-keyed values. Missing and N/A remain distinct; sums require complete cases and partial means require an explicit minimum answered count, showing n/N. No overall score, norms, cutoffs or psychometric validity is inferred. Use native keyboard and accessibility checks before relying on the interface.

Assessment copy downloads

The session-only assessment workspace can create a reviewed blank respondent DOCX and a separate PRIVATE author scoring guide. Capture a valid current definition, choose the copy, optional export instructions and base language, refresh the complete review and acknowledge it. PRIVATE guides require their own additional acknowledgement. Neither copy contains entered synthetic responses or scored results. Authored public text is reproduced as written; check it for keys you typed into prompts or labels. Downloading does not save an editable assessment draft or insert content into Word. Base language does not tag mixed-language spans. Layout, keyboard and native accessibility qualification remain separate.

Optional public cover and copyright for a new workbook copy

In the five-design workbook preview, independently choose Include cover and Include copyright. Both start off, so the prior output stays unchanged. Organization comes from your public branding control. Enter cover title/subtitle, author, edition/year and audience explicitly. The public cover title changes only the generated copy title and filename, not the source course.

Rights holder is separate from author and organization. Enter a year or ordered range, choose a notice and edit its text. Named licenses require an authored name, version and HTTP/HTTPS terms URL; the add-in does not choose or verify a license. A requested starter replaces text only after an explicit Keep/Replace choice. Reset likewise asks before removing this raw draft. Review all public wording before sharing. Custom text and brand settings stay across design/scope switches; these front-matter fields are session-only unless explicitly saved in a design bundle and are not included in local brand presets. Logo, contents and research have their own explicit controls and are included in those authoring bundles as described below.

Linked workbook contents

The five-family new-copy route has an optional linked contents choice, off initially and session-only unless explicitly saved in a design bundle. It follows actual included module, learning-objective, activity and copyright headings. Duplicate titles have separate internal targets; omitted selected-plan material stays out. These are snapshot navigation links with no page numbers, TOC/PAGEREF field or automatic update. Manual edits to a downloaded file do not update entry text or calculate pages. Regenerate from saved source after headings change. Qualify native link activation, page layout and accessibility before sharing. Educational research and logo/image assets remain separate work.

Opening educational research

The new-workbook-copy route has an optional opening educational research and rationale section. Enter your own rationale, evidence, course/session application, limitations and references. Nothing is filled from private Background or facilitator content, and claims, citations and applicability are not verified. Nonblank subsections use semantic headings and appear after linked contents before learner content; their headings join the generated contents when included. No findings, citation formatting or references are invented.

The research draft is session-only unless explicitly saved in a design bundle and can otherwise be lost on reload or another Word-document pane. Switching design, scope, branding, cover/copyright or contents retains your words. Reset asks Keep/Replace and clears only research fields; pending replacement blocks preview/Apply. Review the exact included text before downloading. Native layout, keyboard/screen-reader and accessibility qualification remain separate; actual logo/image assets are not part of this section.

Workbook design bundle files

On Workbook, use Save PRIVATE workbook design bundle to offer a local JSON authoring file. It includes raw family/language/branding, public front matter, contents/research choices and only the current verified PNG. Resolve loading, failed or pending logo choices before saving; an older hidden image is never silently substituted. The bundle excludes course/selected-plan content and selections, assessments, responses, consent and local preset catalogs. Check selected design bundle prepares a candidate; Keep preserves current work and Replace changes only design fields and logo. PNG bytes are checked and normalized again under current policy into a fresh session handle. Review the current thumbnail, design values and generated output again before export. Unsupported/malformed/oversize files and stale/canceled reads keep current work. No original file is rewritten, no migration or automatic storage occurs, and these source controls are not native accessibility or Word-layout certification.
