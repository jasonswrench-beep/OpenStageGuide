Training icons for inserting into Word documents.

These are 192-pixel copies of the training icons in ../icons, scaled down so a guide does not carry a quarter of a megabyte per icon. They are the same artwork under the same licence: Creative Commons Attribution-NonCommercial-ShareAlike 4.0 International, https://creativecommons.org/licenses/by-nc-sa/4.0/. The icons were created and supplied by Jason Wrench. Software licensing is separate.

File names are lower case with hyphens so they are safe in a web address. Each cue in src/guide-cues.mjs names one of these files.

New cue icons (added 2026-11-06): 48 more files in this folder (every one that is not among the original fourteen listed above), each
the picture of one cue, supplied by Jason S. Wrench as 1024-pixel PNGs and vector SVGs and shrunk to 192 pixels with
scripts/make-cue-icons.ps1. The vector masters are in docs/icons-source. Unlike the original fourteen, these 48 are licensed under the Apache License 2.0, like the code (decided by the author on 2026-11-06; see NOTICE). A
revised icon replaces its file by running that script on it.

Stand-in cue icons (added 2026-11-15): expected-answer, debrief, option, set-up and clean-up, five simple pictures drawn by scripts/make-stand-in-icons.mjs in the style of the others (a black ring and a bold black picture), with their vector files in docs/icons-source. They are licensed under the Apache License 2.0, like the code, and stand in until the author supplies his own artwork; a revised icon replaces its file by running scripts/make-cue-icons.ps1 on it.
