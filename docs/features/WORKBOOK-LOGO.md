# Informative cover logo asset extension v1

**Manual design-bundle exception.** A verified logo handle remains private to one pane session, but the explicit workbook-design Save/Load feature can retain normalized PNG bytes and raw logo text in a separate versioned local authoring file. Loading rechecks the PNG under current policy and creates a fresh owned handle; no opaque handle, review consent or accessibility claim is restored. Nothing is saved automatically to the course, presets or a service. See [workbook design file contracts](WORKBOOK-DESIGN-FILES.md).

This bounded source extension adds one optional informative PNG logo to the public cover of a newly generated family workbook. It is not native Word insertion or a release qualification. Existing course/publication/research/contents/scoring schemas and the sixteen-field saved brand preset remain unchanged.

## Session and privacy boundary

Logo inclusion starts off. The image, classification, alt text and display width are session-only, separately reviewed draft state. They remain across family/scope/publication/brand changes but are not saved into the course, localStorage or presets. Reload/document switching may lose them; an attempted unload warning is best-effort. Existing live family preview/Apply retains inherited refresh/persist behavior; this extension adds no logo data to its course payload.

A local file is read only after explicit selection. Source filenames/paths and descriptive PNG metadata never enter the generated DOCX. Pixel content itself can contain information; normalization is not a steganography-removal or rights check. No image is fetched or transmitted to a service. Organization, author, rights or license are never inferred from the image.

## Validation and verified handle

`prepareWorkbookLogo(bytes)` asynchronously copies an ordinary Uint8Array before its first await, validates a bounded PNG, sanitizes/recompresses the scanlines, and returns a frozen module-owned session handle. Normalized image bytes remain private in a WeakMap. Copied/forged handles and declared hash/dimension claims do not substitute for verification. `workbookLogoInfo(handle)` returns a new frozen public identity/dimensions/hash summary; `workbookLogoBytes(handle)` returns a fresh private-byte copy.

Initial PNG support is 8-bit RGB or RGBA, noninterlaced and nonanimated. Limits are 2 MiB input/output, 2048 pixels per dimension and 4,194,304 pixels. Validate signature, chunk lengths/order/CRCs, IHDR, contiguous IDAT, final IEND, bounded decoded length and row filters 0–4. Recompress only validated scanlines into fresh IHDR/IDAT/IEND chunks. Untagged/default-sRGB and an exact valid sRGB chunk are accepted; iCCP, gAMA and cHRM are explicitly unsupported to avoid claiming that profile removal preserves brand appearance. Only known descriptive tEXt/zTXt/iTXt/eXIf/tIME chunks are stripped; descriptive payload syntax is not fully interpreted. tRNS, bKGD, palette/unknown rendering chunks and animation are refused. pHYs must occur at most once before IDAT and declare equal X/Y density; explicit export geometry then makes safe density metadata unnecessary. EXIF orientation is removed: the normalized pixel preview is the review authority, and identical appearance to an EXIF-aware source viewer is not promised. JPEG, SVG, APNG and other PNG encodings are unsupported, not silently converted.

## Authored logo choice and rendering

Canonical options are exact own-data `{schemaVersion:1, include:false, asset:null, role:'', alt:'', widthIn:null}`. Included logos require an enabled cover, a verified handle, explicit informative role, nonblank XML-safe authored alt text and finite width 0.5–3 inches. Decorative intent remains a draft but active decorative export refuses until supported encoding and native behavior are qualified. Empty alt text or hidden properties are never treated as decorative.

The image is a normal-flow `w:p/w:r/w:drawing/wp:inline` with generic names, a fixed internal PNG relationship and authored `wp:docPr/@descr`. Geometry preserves aspect ratio within usable page width and a 2-inch height limit; actual applied dimensions are shown in preview. No cropping, stretching, floating anchors or recoloring occurs. Logo pixel colors remain unchanged even when text/rule print mode is grayscale; inspect a printed output. Alt quality, image contrast/color fidelity, native screen-reader behavior and Accessibility Checker success remain author/native review tasks.

## Separate package profile

Omitted/off logos preserve the preceding accepted seven-part files and preview byte-for-byte. Included logos use generated profile 4 plus logo asset extension 1: those seven parts and fixed `word/media/organization-logo.png` only, one PNG content type and one internal image relationship. The media-map value is normalized base64. A private renderer WeakMap seals each enabled output and exact expected parts; only the exact owned output can be packaged. The capture API returns fresh byte copies, never its private canonical buffer. Cloned output, forged preview/geometry/hash and mutated maps are refused. It captures exact expected XML/media bytes before awaits and validates raw ZIP inventory, metadata, CRC, UTF-8 and binary readback. No external image link or user filename is serialized. The shared seven-string-part `familyWorkbookBlob` remains unchanged because other exports reuse it; a new output dispatcher selects the strict logo serializer only for profile 4.

## Draft and review protection

The file input uses a captured local File stream, copies each byte chunk immediately, caps declared/actual bytes at 2 MiB and at most 4096 reads, and cancels stale/oversized/incomplete reads. File-load generations, selected file identity, normalization state, handle/hash, role, alt, width, source/scope/family, visibility, exact displayed review and consent bind before and after asynchronous reads/packaging. Failed replacements retain the last valid asset explicitly, invalidate the current offer and never silently export it under an invalid new selection. Restore/remove/reset uses guarded Keep/Replace. Cancellation preserves the current draft. Other branding/publication/research/contents/course drafts remain unchanged.

Tests must cover all five families/full-selected scopes, disabled compatibility, one image per copy, alt/proportions/relationships, metadata canaries, malformed/oversized PNGs, forged handles, retained-buffer mutation, selection/package races, repeated downloads and unchanged legacy serializers. Source/XML/package checks do not qualify native Word appearance, links, accessibility, print or PDF.

## API and draft shape

`validateWorkbookLogo(choice)` accepts exactly the six canonical own-data fields shown above. Omission of `logo` at `renderWorkbookFamily` or `prepareFamilyWorkbook` leaves the original profile unchanged. An off choice can retain a verified asset, role/alt and valid width; inactive raw width is retained as text by the panel and normalized to null only in the canonical off projection. A forged non-null asset is refused even when off.

`workbookLogoRequest(raw)` accepts schemaVersion, include `{checked,value,invalid}`, role/alt/widthIn `{value,invalid}`, and selection `{state,generation,asset,current}`. Invalidity uses the same ten native validity flags as existing brand controls. The selection is empty/ready/loading/invalid; active export requires ready and current. Filenames, paths and UI File objects are not canonical fields. `workbookLogoPresentation(choice, frame)` reports pixel dimensions, requested inches, fitted inches/EMU, role, normalized authored alt and verified identity; frame is `{coverIncluded,pageWidthTwips,marginTwips}`.

Included renderer outputs have exactly profileVersion, assetProfileVersion, logoAsset, familyId, familyVersion, preview and files. `captureWorkbookLogoOutput(output)` refuses non-owned output and exposes only a copied snapshot for the strict serializer. `familyWorkbookOutputBlob(output, Zip)` dispatches exact owned profile 4 output to the separate logo package serializer; old profile 3 output goes through the unchanged seven-string-part helper. Existing assessments, packs and legacy workbook generators retain their old contracts.

`mountWorkbookLogoPanel` owns current/last-valid handles and asynchronous generations. It exposes raw/identity/displayState, pending/loading/busy and best-effort unload methods. Replacement, restore, remove and reset have explicit Keep/Replace choices. A failed or newly pending selection is never exported under the previous image; Restore is an explicit action. Include/role/alt/width remain independently authored. The image preview's src, alt, width, height, visibility, style and structure join the source/scope/brand/publication/contents/research/stamp/consent review guards. This is a local source image preview, not a rendered Word cover.
